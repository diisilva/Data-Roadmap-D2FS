# Dataset FEC omitido do snapshot

O arquivo `P00000001-ALL.csv` existe no commit upstream registrado em `SOURCES.md`, mas foi removido deste snapshot porque possui aproximadamente 150 MB e ultrapassa o limite normal de arquivo do GitHub.

Ele é necessário apenas para o exemplo de dados da Federal Election Commission. Para executar esse exemplo, obtenha o arquivo diretamente no repositório [wesm/pydata-book](https://github.com/wesm/pydata-book/tree/3rd-edition/datasets/fec) e coloque-o nesta pasta, preservando o nome original.

Os demais capítulos e exemplos não dependem desse arquivo.
