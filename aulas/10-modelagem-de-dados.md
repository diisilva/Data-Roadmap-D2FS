# Aula 10 — Modelagem de dados

**Navegação:** [← Aula 09](./09-revisao-do-case-analitico.md) | [Índice](../README.md) | [Próxima →](./11-modelagem-dimensional.md)

## Objetivo

Derivar modelos conceitual, lógico e físico a partir dos requisitos do case.

## Estude nesta ordem

1. [Data Modeling](<../materials/data-engineering-wiki/Concepts/Data Modeling/Data Modeling.md>).
2. [Relational Modeling](<../materials/data-engineering-wiki/Concepts/Data Modeling/Relational Modeling.md>).
3. [Normalization](<../materials/data-engineering-wiki/Concepts/Data Modeling/Normalization.md>).
4. [Denormalization](<../materials/data-engineering-wiki/Concepts/Data Modeling/Denormalization.md>).

## Prática

Modele entidades, relacionamentos, cardinalidades, chaves e restrições. Depois transforme o modelo lógico em DDL.

## Entrega

Diagrama, dicionário de dados e script DDL.

## Avance quando

- [ ] Cada tabela possui uma finalidade e uma chave.
- [ ] Cardinalidades e integridade referencial estão explícitas.
- [ ] Toda desnormalização possui justificativa mensurável.
