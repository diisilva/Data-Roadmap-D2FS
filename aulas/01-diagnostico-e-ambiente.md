# Aula 01 — Diagnóstico e ambiente

**Navegação:** [Índice](../README.md) | [Próxima →](./02-qualidade-e-primeira-decisao.md)

## Objetivo

Confirmar os pré-requisitos, escolher um conjunto de dados e preparar um projeto que outra pessoa consiga executar.

## Estude nesta ordem

1. [Getting Started With Data Engineering](<../materials/data-engineering-wiki/Guides/Getting Started With Data Engineering.md>).
2. [README do Python for Data Analysis](../materials/python-data-analysis/README.md), apenas instalação e organização dos notebooks.
3. [Diagnóstico inicial](../PROGRESS.md#diagnóstico-inicial).

## Prática

Escolha um dataset com origem e dicionário conhecidos. Crie um repositório de exercício com ambiente virtual, dependências declaradas e um comando que leia cinco registros.

## Entrega

`README.md`, arquivo de dependências e script de leitura.

## Avance quando

- [ ] Uma instalação limpa funciona usando somente o README.
- [ ] A origem e a licença dos dados estão registradas.
- [ ] Os pré-requisitos foram preenchidos em `PROGRESS.md`.
